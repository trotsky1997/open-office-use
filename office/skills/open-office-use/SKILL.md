# Open Office Use

Read the office/README.md for installation, commands, MCP tools, spec formats and limitations. For multi-step work, use a session directory and pass the latest revision as the base for each edit. The viewer can preview or compare earlier revisions, including bounded text, file-part and XLSX cell diffs, before `session_restore` or its restore control copies a prior revision into a new revision when requested. When a user wants to watch progress, run `office-use watch` for the session and share its local URL. The viewer can search a saved selection for candidate paths; the user can choose a candidate to load. For XLSX, the viewer and MCP can load and edit a bounded grid, with formulas marked by `=` and explicit version checks. The viewer supports rectangular tab-separated grid paste with bounds and formula protection. Grid formatting supports bold, RGB fill and number formats for a selected subrange. For a unique literal replacement in a simple Word body or table-cell paragraph a supported PowerPoint shape or table-cell paragraph, or an Excel text cell, use `session_replace_text` to retain run formatting; Word matches must stay within hyperlink or annotation boundaries. Excel formula caches may become stale; inspect and recalculate when appropriate. Other structural restrictions apply. The viewer and MCP can also load and edit supported elements by explicit path; verify the element and version first. If the user selects an area, read `session_selection`, `session_selection_image` and, when useful, `session_selection_text` and `session_selection_candidates`; check its revision and stale flag, then verify candidate elements with structured reads and visual context. Repeated or missing text can produce ambiguous results. Selected PDF text may omit image or partially selected text. Inspect source files before editing. Write to a new output path. For structured operations use OfficeCLI through `office-use structured` and `office-use batch` when installed. Save and close the source first. Run `audit` or `audit_file` and inspect validation and issues before delivery. Use `compare` or `compare_files` to review text and package changes in saved files; inspect the actual content and rendered pages for details. Use `office-use preview` to render page PNGs and inspect them visually before delivery. Use `scan-formulas` or `scan_formulas` to check stored formula caches and error cells across worksheets, checking its completion and truncation flags. Use `cells` or `read_cells` to inspect formulas and cached values, and `compare-cells` or `compare_cells` for range-level value, formula and direct-formatting changes. Review conditional formatting and theme changes separately. Cache freshness is unknown. When appropriate, use `recalculate` or `recalculate_workbook` to make a LibreOffice-calculated copy, check errors, and review conversion fidelity. Inform the user about any fidelity or feature limitations relevant to their file.
