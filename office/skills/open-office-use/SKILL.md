# Open Office Use

Read the office/README.md for installation, commands, MCP tools, spec formats and limitations. For multi-step work, use a session directory and pass the latest revision as the base for each edit. The viewer can preview or compare earlier revisions, including bounded text, file-part and XLSX cell diffs, before `session_restore` or its restore control copies a prior revision into a new revision when requested. When a user wants to watch progress, run `office-use watch` for the session and share its local URL. The viewer can search a saved selection for candidate paths; the user can choose a candidate to load. For XLSX, the viewer and MCP can load and edit a bounded grid, with formulas marked by `=` and explicit version checks. The viewer supports rectangular tab-separated grid paste with bounds and formula protection. Grid formatting supports bold, RGB fill and number formats for a selected subrange. For a unique literal replacement in a simple Word body or table-cell paragraph, a supported PowerPoint shape or table-cell paragraph, or an Excel text cell, use `session_replace_text` to retain run formatting; Word matches must stay within hyperlink or annotation boundaries. Excel formula caches may become stale; inspect and recalculate when appropriate. Other structural restrictions apply. The viewer and MCP can also load and edit supported elements by explicit path; verify the element and version first. If the user selects an area, read `session_selection`, `session_selection_image` and, when useful, `session_selection_text` and `session_selection_candidates`; check its revision and stale flag, then verify candidate elements with structured reads and visual context. PowerPoint selection candidates can also match visible shape geometry when page mapping is reliable, including images; verify geometry matches and text matches against the rendered slide. Repeated or missing text can produce ambiguous results. Selected PDF text may omit image or partially selected text. Inspect source files before editing. Write to a new output path. For structured operations use OfficeCLI through `office-use structured` and `office-use batch` when installed. Save and close the source first. Run `audit` or `audit_file` and inspect validation and issues before delivery. Use `compare` or `compare_files` to review text and package changes in saved files; use `compare_page_images` or `session_compare_page_images` for corresponding rendered page comparisons; inspect the actual content and rendered pages for details. Use `session_add_comment` for a plain-text review comment on a simple Word body or table paragraph; the comment covers the entire paragraph. Existing supported modern comment metadata is updated alongside the new root. Use `list_word_comments` or `session_list_comments` to inspect bounded comments and main-body anchor hints. Word 2013 comment thread parents and resolved status are reported when metadata maps unambiguously; unmatched or malformed states remain unknown. Use `session_reply_comment` to reply to a supported open root comment and `session_resolve_comment` to resolve or reopen one in a new revision. For an embedded PowerPoint picture, use `session_replace_picture` with a local PNG or JPEG and inspect the rendered revision; the existing crop remains. For PowerPoint, use `inspect-layout` / `inspect_slide_layout` or `session_inspect_slide_layout` to locate off-slide and overlap candidates; inspect the completeness flags, verify paths and distinguish intentional layering. Use `view_contact_sheet` or `session_contact_sheet` for a numbered multi-page overview, then use `view_document_page` or `session_view_page` to inspect individual rendered pages and optional normalized crops before delivery, including text overflow and master content. Use `scan-formulas` or `scan_formulas` to check stored formula caches and error cells across worksheets, checking its completion and truncation flags. Use `cells` or `read_cells` to inspect formulas and cached values, and `compare-cells` or `compare_cells` for range-level value, formula and direct-formatting changes. Review conditional formatting and theme changes separately. Cache freshness is unknown. When appropriate, use `session_recalculate` for a new XLSX session revision or `recalculate` / `recalculate_workbook` for a separate LibreOffice-calculated copy; use `session_scan_formulas` to check the latest session revision, inspect errors, and review conversion fidelity. Inform the user about any fidelity or feature limitations relevant to their file.
