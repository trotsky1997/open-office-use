# Open Office Use

Read the office/README.md for installation, commands, spec formats and limitations. Inspect source files before editing. Write to a new output path. For structured operations use OfficeCLI through `office-use structured` and `office-use batch` when installed. Save and close the source first. Use `office-use preview` to render page PNGs and inspect them visually before delivery. Preserve formulas where useful and verify calculated values with a calculation engine. Inform the user about any fidelity or feature limitations relevant to their file.
